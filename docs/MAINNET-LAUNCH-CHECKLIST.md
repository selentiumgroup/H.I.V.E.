# Neural Mesh v1.0 Mainnet Launch Checklist

v1.0 is feature-frozen. Do not add protocol features during the launch window.

## Mandatory launch gates

- Independent cryptographic/security audit completed and findings remediated.
- Multi-region adversarial testnet completed, including partitions, leader loss, Byzantine validators, replay, foreign-network traffic and relay loss.
- Sustained load test completed on the intended validator hardware.
- Every genesis validator independently generated its NodeID/private key; no private key was shared with ceremony coordinators.
- Genesis ceremony manifests were independently signed and publicly witnessed.
- `genesis-ceremony.json`, `network-manifest.json`, release archive SHA-256 and `release-manifest.json` releaseRoot are published through multiple independent channels.
- `npm run release-audit` returns `ok: true`.
- `npm run verify-v1` passes on the release artifact.
- `npm run mainnet-preflight` passes on every validator.
- Hardware/HSM-backed validator keys are strongly recommended for economically material mainnet stake.
- Emergency halt/resume and validator recovery procedures are rehearsed by operators before genesis.

## Never do this

- Do not use the template mainnet manifest as genesis.
- Do not reuse testnet NodeID/private keys for mainnet validators.
- Do not launch with `AUTO_BOOTSTRAP_VALIDATORS=true`, untrusted testnet fast-sync, autogenerated local keystore secrets or a short API token.
- Do not claim an independent audit occurred unless an independent reviewer actually completed one.
